# Markdown 示例库

这些页面都是可以直接复用的 Markdown 源文件。先用普通 Markdown 确认基线，再看各主题的扩展。

示例 可以看到什么
Markdown 语法 标题、表格、列表、链接、图像、脚注、定义列表、标记和上下标
技术文档与图表 LaTeX 公式、代码高亮、包管理器命令和流程图
主题专属能力 本站主题的卡片、容器和交互组件
Muya 对照样例 用于后续 AST 适配的同源用例，含嵌套、转义和分隔符边界
