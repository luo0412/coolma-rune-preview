# 文字、链接与换行

粗体、斜体、删除线、行内代码、高亮、H2O、x2。这是一个站内引用链接，也是一个脚注示例[1]。

第一行末尾有两个空格。
第二行会硬换行。

# 表格、引用与定义列表

数据 类型 说明
tokens 数组 Markdown 解析结果
html 字符串 页面渲染结果

给读者看的说明可以包含 强调。

引用也可以嵌套。

Markdown token
解析器输出的语法单元。
一个语法单元也可以包含子节点。
